# 饥渴平衡备忘（普通套餐 · 谨慎吃喝）

## 首段误杀修复

- **根因**：`applyNeedsPassiveDrain` 使用 `hours × (foodNeed×5.5 + …)`，而 `foodNeed` 本段又按 `hours/4` 增长，单段最长约 3.5h 时会出现近似 **hours²** 扣体；再配合 `waterNeed` 一次跨过 1.0 的 **22 点尖峰**，满体力首步即死（并非 `stam` 未重置）。
- **修复**：被动扣体改为「分档 + 轻度 need 系数」；饮水累积 `hours/4`（单段不再必跨 1.0）；单段饥渴扣体上限 `16 + hours×4.5`；`finishShop` / `startNewRun` 显式 `resetRunVitality()`。
